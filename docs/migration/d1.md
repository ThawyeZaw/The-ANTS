# Phase 3 — D1 + Better Auth

> Tracker: [`cloudflare.md`](./cloudflare.md)

## Goal

- `packages/db` uses **SQLite / D1** (`sqlite-core`), not Neon Postgres
- Better Auth uses `drizzleAdapter` with `provider: 'sqlite'`
- Web Worker (`the-ants-web`) and API Worker (`the-ants-api`) share D1 binding **`DB`** → database **`the-ants-db`**
- R2 unchanged

## (A) Repo status (agent)

- Schema ported to `sqlite-core` (text UUIDs, JSON-as-text, timestamp_ms booleans)
- Initial migration: `packages/db/drizzle-d1/0000_*.sql`
- `createDb(env.DB)` only — Neon URL client removed
- API auth + cron use D1
- Web `getDb()` reads OpenNext `getCloudflareContext().env.DB`
- Wrangler configs include `d1_databases` with placeholder `database_id`

## (B) You — create D1 and wire IDs (required before deploy)

### 1. Create the database

```bash
npx wrangler login
npx wrangler d1 create the-ants-db
```

Copy the printed **`database_id`** (UUID).

### 2. Patch both wrangler configs

Replace `REPLACE_WITH_D1_DATABASE_ID` in:

- `apps/api/wrangler.jsonc`
- `apps/web/wrangler.jsonc`

with the same `database_id`.

### 3. Apply migrations

Local (for `cf:preview` / `wrangler dev`):

```bash
npx wrangler d1 migrations apply the-ants-db --local -c apps/api/wrangler.jsonc
```

Remote (production D1):

```bash
npx wrangler d1 migrations apply the-ants-db --remote -c apps/api/wrangler.jsonc
```

**Verify:**

```bash
npx wrangler d1 execute the-ants-db --local -c apps/api/wrangler.jsonc --command "SELECT name FROM sqlite_master WHERE type='table' ORDER BY name;"
```

Expect tables including `user`, `session`, `profiles`, `exams`, `notification_queue`, …

### 4. Redeploy Workers

```bash
cd apps/api && npx wrangler deploy
npm run cf:deploy:web
```

### 5. Smoke-test auth (browser — not a PowerShell command)

“Smoke-test signup” means **manually create an account in the browser**, then verify D1 with SQL.

1. Ensure web Worker has `NEXT_PUBLIC_API_URL` (in `apps/web/wrangler.jsonc` `vars`, then redeploy web).
2. Open: `https://the-ants-web.thawyezaw.workers.dev/signup`
3. Register with a real email + password you control.
4. Then run:

```bash
npx wrangler d1 execute the-ants-db --remote -c apps/api/wrangler.jsonc --command "SELECT id, email FROM user LIMIT 5;"
```

Expect your new email in the results. Empty results before signup are normal.

## Type mappings (reference)

| Postgres | D1 / SQLite |
|---|---|
| `uuid` | `text` (app UUID) |
| `jsonb` / `text[]` | `text` JSON |
| `timestamptz` | `integer` ms epoch |
| `boolean` | `integer` 0/1 |

## Notes

- **Vercel production** cannot run server actions that call `getDb()` (no D1). Until Phase 6, use **Cloudflare web preview** for DB-backed flows; keep the Neon project until Phase 6 cutover (Phase 5 = optional data copy).
- Postgres SQL migrations under `packages/db/drizzle/` are **historical archive only** — new migrations go in `drizzle-d1/`.
- Data copy Neon → D1 is **Phase 5** — **skipped** (2026-09-12: no important Neon data). Neon project remains only until Phase 6 decommission.
- Canonical API URL: **`https://api.the-ants.org`** (workers.dev alias still works; clients should prefer custom domain).
- `R2_PUBLIC_BASE_URL` is optional. Bucket `the-ants-assets` stays private; public URLs are Worker routes `/api/storage/file/...` defaulting to `https://api.the-ants.org`.
